       - `final Map<String, dynamic> headerJson;`
       - Konstruktor `const EncryptedPayload({required this.ciphertextBlob, required this.headerJson});`
     * Definisikan class `E2eeCryptoService`:
       - `static EncryptedPayload encrypt(String plaintext, String keyString)`:
         * Pastikan key memiliki panjang tepat 32 byte (misal jika kurang/lebih, derive menggunakan SHA-256 via `sha256.convert(utf8.encode(keyString)).bytes` dari package `crypto`).
         * Generate IV acak 16 byte (`enc.IV.fromSecureRandom(16)`).
         * Enkripsi plaintext menggunakan `enc.Encrypter(enc.AES(enc.Key(keyBytes), mode: enc.AESMode.cbc))` dan kembalikan `EncryptedPayload(ciphertextBlob: encrypted.base64, headerJson: {'iv': iv.base64, 'algorithm': 'AES-256-CBC'})`.
       - `static String decrypt(String ciphertextBlob, String keyString, String ivBase64)`:
         * Derive key 32 byte.
         * Decode `enc.IV.fromBase64(ivBase64)`.
         * Dekripsi `encrypter.decrypt64(ciphertextBlob, iv: iv)` dan kembalikan string plaintext.
